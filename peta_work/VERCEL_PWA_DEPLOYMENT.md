# PETA PIANO AI — Vercel + Premium PWA

## Included
- Existing Vite + React application and Kie.ai API Functions.
- Vercel configuration (`vercel.json`).
- PWA manifest generated by `vite-plugin-pwa`.
- Auto-updating service worker for the app shell.
- Premium PETA PIANO AI icon assets: 192x192, 512x512, and Apple Touch Icon 180x180.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload the CONTENTS of this folder to a GitHub repository (do not upload the ZIP as one file).
3. Import the repository into Vercel.
4. Root Directory: `./`
5. Framework Preset: Vite
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Install Command: `npm install`
9. Deploy.

## Install as an app
After production deployment over HTTPS:
- Android Chrome: open the site menu and choose Install app / Add to Home screen.
- iOS Safari: Share > Add to Home Screen.

## API key
The app uses the Kie.ai key entered by the user in the app's API Manager. Do not commit a real API key or put it in public source code.

## Notes
- The service worker caches the static app shell/assets, not `/api/` responses.
- A PWA install does not make generation work offline; Kie.ai generation requires an internet connection.
- Build and real Vercel deployment still need to be tested after importing the repository.
